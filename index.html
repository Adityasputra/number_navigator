#

Number Navigator

Ambil nomor dari spreadsheet, lalu salin satu per satu.

Simpan spreadsheet sebagai CSV UTF-8. Untuk nomor telepon, sebaiknya format kolom sebagai teks agar angka nol di depan tetap ada.

Agar bisa diakses, gunakan File → Share atau publikasikan sheet sebagai CSV. Jangan gunakan link pribadi yang meminta login. Data tetap diambil dari sumber yang Anda berikan.

Pilih file CSV atau hubungkan Google Sheets untuk memulai.

Pengaturan kolom
